# BCMS Portal v2.4

ISO 22301 + 재해경감우수기업 통합 관리 포털

## 주요 기능
- BIA (업무영향분석) 및 리스크 평가
- BCP 전략 수립 및 연속성 절차 관리
- 훈련·점검 관리
- ISO 22301 갭분석 및 재해경감우수기업 점검 (2026 기준)
- 경영진 보고서 (인쇄/Word 다운로드)

## 기술 스택
- 순수 HTML/CSS/JavaScript
- localStorage 기반 데이터 저장
- 백엔드 없음 (정적 사이트)

## 실행 방법
VS Code + Live Server 로 index.html 열기

## 배포
Netlify 정적 배포

## 기준
- ISO 22301:2019
- 기업재난관리표준 (행정안전부 고시 제2025-42호, 2026.01.01 시행)
