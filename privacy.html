제 1 조
총칙 및 목적

BCMS Portal(이하 "서비스")은 사용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령을 준수합니다.

본 방침은 서비스 이용과 관련하여 수집되는 개인정보의 항목, 수집·이용 목적, 보유·이용 기간, 제3자 제공 여부 및 파기 절차 등을 안내합니다.

⚠️ 현재 버전 안내
BCMS Portal 현재 버전(v2.4)은 서버리스(Serverless) 구조로 운영됩니다. 사용자가 입력한 모든 데이터는 사용자 본인 기기의 브라우저 로컬 스토리지(localStorage)에만 저장되며, 외부 서버로 전송되지 않습니다.

수집하는 개인정보 항목

서비스는 아래와 같은 정보를 수집할 수 있습니다.

구분 수집 항목 수집 방법 필수 여부
식별 정보 이름 사용자 직접 입력 선택
연락처 이메일 주소, 전화번호 사용자 직접 입력 선택
소속 정보 회사명, 부서명 사용자 직접 입력 선택
서비스 이용 정보 BCMS 수립 데이터, BIA/RA 데이터, 훈련·감사 기록 사용자 직접 입력 선택
기기 환경 정보 테마 설정(라이트/다크), 교육 진행 상태 자동 저장 —

위 모든 정보는 사용자 기기의 브라우저 localStorage에만 저장되며, 서비스 서버 또는 제3자에게 전송되지 않습니다.

제 3 조
개인정보 수집·이용 목적

수집된 정보는 아래 목적으로만 이용됩니다.

  • BCMS 수립 문서 및 보고서 자동 생성·표시
  • BIA, 리스크 평가, BCP 전략 등 데이터 분석 및 시각화
  • ISO 22301 갭분석 및 진행률 산출
  • 사용자 설정(테마, 교육 진도 등) 유지

위 목적 이외의 용도로 개인정보를 이용하지 않으며, 목적 변경 시 사전 동의를 받겠습니다.

제 4 조
저장 위치 및 외부 전송
✓ 외부 전송 없음 (No External Transfer)

사용자가 입력한 모든 데이터는 아래와 같이 처리됩니다.

항목 내용
저장 위치 사용자 본인 기기의 브라우저 localStorage
서버 전송 없음 — 외부 서버로 데이터를 전송하지 않습니다
제3자 제공 없음 — 어떠한 제3자에게도 데이터를 제공하지 않습니다
클라우드 동기화 없음 — 다른 기기와 데이터가 동기화되지 않습니다
쿠키(Cookie) 사용하지 않음
분석 도구 사용하지 않음 (Google Analytics 등 미사용)
📌 참고: localStorage는 브라우저를 초기화하거나 캐시·사이트 데이터를 삭제하면 모든 데이터가 영구적으로 삭제됩니다. 중요한 데이터는 보고서 PDF 출력 또는 별도 백업을 권장합니다.
제 5 조
개인정보 보유 및 파기
구분 보유 기간 파기 방법
BCMS 수립 데이터 사용자가 직접 삭제할 때까지 브라우저 localStorage 삭제 또는 직접 초기화
테마·설정 정보 사용자가 직접 삭제할 때까지 브라우저 캐시·사이트 데이터 삭제
교육 진행 상태 사용자가 직접 삭제할 때까지 브라우저 localStorage 삭제

서비스는 별도의 서버 데이터베이스를 운영하지 않으므로, 사용자 측에서 브라우저 데이터를 삭제하면 모든 정보가 즉시 파기됩니다.

각 브라우저에서 localStorage를 삭제하는 방법: 설정 → 개인정보 보호 → 사이트 데이터 삭제 (브라우저별 메뉴 명칭은 상이할 수 있습니다.)

제 6 조
사용자의 권리

사용자는 언제든지 아래 권리를 행사할 수 있습니다.

  • 열람권: 브라우저 개발자 도구(F12) → Application → localStorage에서 직접 확인 가능
  • 정정권: 각 페이지의 수정 기능을 통해 직접 수정 가능
  • 삭제권: 브라우저 사이트 데이터 삭제 또는 각 페이지의 초기화 기능 이용
  • 처리 정지권: 서비스 이용을 중단하면 더 이상 정보가 저장되지 않습니다
